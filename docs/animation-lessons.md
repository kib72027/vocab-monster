# 主角動畫：踩過的坑與規則（務必遵守）

這份記錄 2026-11-20 修主角逐格動畫時犯過的錯，以後改動畫前先讀。

## 規則

1. **不同姿勢之間不要淡入淡出。** 攻擊、受傷、勝利一律直接換格（硬切）。
   淡入淡出兩個不同姿勢會疊出兩個人的殘影，看起來像分割或閃動。
   只有**待機循環**、而且是**彼此很像的格**之間才能淡入淡出。
2. **待機只用和其他動作同方向、彼此相似的格。** AI 的待機格常常轉頭、換方向（正面 → 側面）。
   `tools/mkhsheet.py` 會自動挑出最像攻擊／受傷／勝利開頭與結尾的那一格當待機基準，
   只留差異小於門檻的格；一格都不像就只用那一格，由程式加輕微呼吸。
3. **攻擊、受傷只用關鍵姿勢**（攻擊：蓄力、出招；受傷：受擊一格），身體移動交給程式。
   AI 的 6～8 格前後姿勢跳太大，全部播會卡。
4. **每格用腳底對齊**（腳不會動），不要用整張圖的中心或格子位置；AI 每一列畫的高度也不同。
5. **透明像素要填入邊緣顏色**（bleed），WebP 要用 `exact=True`，不然縮放時會滲出白邊。
6. **WebGL 混合要分開處理 alpha**：
   `gl.blendFuncSeparate(SRC_ALPHA, ONE_MINUS_SRC_ALPHA, ONE, ONE_MINUS_SRC_ALPHA)`。
   用一般 `blendFunc` 時，半透明疊圖會讓畫布 alpha 變低，透出後面淺色頁面 → 主角忽亮忽暗。
   **不要**用 `(…, ZERO, ONE)`（會出現白塊），也**不要**把 clearColor 的 alpha 設成 1（天空會變黑，天空是頁面 CSS 透出來的）。

## 改動畫前的檢查

- 用 `tools/mkhsheet.py <id>` 產生，看它印出的 `idle ref` 和 `loop`。
- 把每個動作的格子排成一張圖親眼看：方向是否一致、有沒有轉頭。
- 實際在遊戲裡錄影或請使用者錄影確認；截靜態圖看不出殘影和閃動。
