Reading Plus 單字打怪王
用瀏覽器開啟 index.html 即可（建議 Chrome / Safari / Edge，電腦、手機、平板都可以）。
- 首頁是 3D 打怪遊戲：40 課各有一隻專屬怪物；每週一隻精英怪（整週單字，10 題）；每兩週一隻魔王（兩週單字，14 題）。
- 解鎖：該週每課 2 星以上 → 挑戰精英；兩位精英 2 星以上 → 挑戰魔王。
- 星星：依正確率給 1～3 星；1 星獎勵減少，沒有寶箱，也不能收服怪物。
- 防亂點：精英／魔王答錯會補血；選項出現 1.2 秒內點擊無效；答錯後要先看正確答案 2 秒才能繼續。
- 題目全英文，每個單字有 3 個解釋和 3 個例句，隨機出題；答對會唸例句。能量滿時再答對會發動大絕招。
- 「更換主角」可從 10 位英雄中選一位。
- 「怪物圖鑑」共 96 隻怪物（普通、精英、魔王、稀有）；打贏怪物（2 星以上）就收服，其他從寶箱抽。
- 「道具商店」用金幣買復活藥水（可使用，回復 3 顆愛心）、提示水晶、單字筆記。
- 「練習模式」可使用單字卡與一般測驗。
- 進度會存在這台裝置的瀏覽器裡。
